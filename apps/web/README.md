# Web application

`@voidmix/web` uses TanStack Start SSR, file routes, Vite, and Nitro's Bun preset. It owns pages and same-origin API adapters. Backend data access goes through the shared HTTP client and the independent API.

```sh
bun run dev:web            # Starts Web and API
bun run build:web
bun run start:web          # Requires built output and a running API
```

The default development port is 3000. `API_ORIGIN` is a server-only API origin, defaulting to `http://127.0.0.1:3002`. Production output is `.output`; `PORT` and `HOST` configure its listener.

## Layout and rendering

- `src/routes`: file routes; `/login` and `/authorize` are shared by native authorization flows.
- `src/routes/api/auth/$.ts` and `api/rpc/$.ts`: same-origin proxy adapters.
- `src/server/api.ts`: server-only upstream URLs, proxying, and per-request credentials.
- `src/lib/orpc.ts`: isomorphic client; SSR calls the API directly, browsers call Web's proxy.
- `src/components`: Web-specific UI and auth layouts.
- `src/routes/__root.tsx`: document shell and the shared UI stylesheet.

SSR credential headers must be read for the current request. Keep the header getter lazy; do not capture a session or mutable headers in a module singleton. Proxy auth redirects manually and preserve cookies and response headers. Server configuration must stay out of client code.

`src/routeTree.gen.ts` is generated by the Start plugin or `bun run --cwd apps/web generate-routes`. Type checking regenerates it. Commit the result and do not edit it manually.

## UI and verification

Import reusable components through `@voidmix/ui/components/*`; keep business layouts here. Use Hugeicons for icons. Add app blocks with `bun run --cwd apps/web ui:add login-01`; shared primitives go through root `ui:add`.

```sh
bun run check
bun run build:web
E2E_DATABASE_URL=postgresql://.../voidmix_e2e bun run test:e2e -- --project=chromium
```

Browser and mobile-viewport Web tests include JavaScript-disabled SSR checks. Authentication and proxy behavior are also covered by the `api` project. See [testing](../../docs/testing.md).
